🔗
Table 4. Configuration Properties for JMSListenerRecoveryConfiguration
Property Type Description Default value

micronaut.jms.listener-recovery.enabled

boolean

Whether listeners recreate a session that the JMS provider reports as failed. Defaults to {@code true}.

true

micronaut.jms.listener-recovery.warn-attempts

int

The number of failed attempts to recreate a session that are logged as warnings. Later attempts are logged as errors, and continue until one succeeds or the listener shuts down. Defaults to 10.

10

micronaut.jms.listener-recovery.initial-delay

java.time.Duration

How long a consumer waits after a failed attempt before the next one. The wait doubles after each attempt, up to {@link #getMaxDelay()}. It must be positive. Defaults to 1 second.

PT1S

micronaut.jms.listener-recovery.max-delay

java.time.Duration

The longest wait between two attempts, which every attempt waits once the doubling reaches it. It must not be shorter than {@link #getInitialDelay()}. Defaults to 1 minute.

PT1M
🔗
Table 5. Configuration Properties for JMSProducerSessionConfiguration
Property Type Description Default value

micronaut.jms.producer-sessions.enabled

boolean

Whether producer methods reuse sessions, on one connection of each connection factory. When disabled, each send takes a connection from the pool and opens a session. Defaults to {@code true}.

true

micronaut.jms.producer-sessions.max-idle

int

The maximum number of idle sessions kept for each connection factory and session mode. While sends wait for a session, released sessions are kept for them up to {@link #getMaxActive()}; the idle sessions above this number are closed once no send waits. Defaults to 8.

8

micronaut.jms.producer-sessions.max-active

int

The maximum number of sessions of each connection factory that sends use at once, of all session modes. When all of them are borrowed, a send waits up to {@link #getMaxWait()} for one to be released. Defaults to 32.

32

micronaut.jms.producer-sessions.max-wait

java.time.Duration

How long a send waits for a session when {@link #getMaxActive()} sessions are borrowed, after which the send fails. Defaults to 10 seconds.

10s
